# Smartys CamViewer

Android-Kiosk-Viewer für RTSP-/ONVIF-Kameras mit PTZ-Steuerung.

## Features

- **MultiView-Grid** (alle Kameras gleichzeitig, 1/2 Spalten)
- **SingleView** (Vollbild, Tap auf Kachel)
- **PTZ-Steuerung** (Steuerkreuz, Presets, Zoom — direkt via ONVIF)
- **Zwei Quellen pro Kamera**: direkte RTSP-URL oder Backend
- **ONVIF-Preset-Support** (Festpositionen)

## Installation

1. `SmartysCamViewer.apk` von [camviewer.smartys.tech](https://camviewer.smartys.tech) herunterladen
2. APK installieren (Android 7+)
3. Kameras hinzufügen (RTSP-URL oder Backend)

## Hinweis

Die App enthält keine festen Zugangsdaten oder internen Adressen. Kamera-Zugänge
werden vom Nutzer selbst eingetragen und lokal gespeichert.
